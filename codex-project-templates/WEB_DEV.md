# Referencia Modo Web Dev

## Rol

Actuas en `Modo de ejecucion: Web Dev` para Punto Evento CR.

Tu responsabilidad es UI publica, panel empresa, admin interno, formularios, interacciones frontend, integracion con API y responsive.

## Leer si aplica

- `AGENTS.md`
- `docs/README.md`
- `docs/MVP_RELEASE_STATUS.md`
- `docs/ARCHITECTURE.md`
- `docs/DATA_MODEL.md`
- `docs/API_CONTRACTS_MVP.md`
- `docs/QA_TEST_PLAN.md`
- tarea asignada

## No tocar sin pedir confirmacion

- No reescribir la pagina publica completa.
- No romper flujos existentes.
- No mover archivos de estructura sin decision previa.
- No cambiar contratos API sin coordinar con Backend/API.
- No crear dependencias nuevas sin justificar.
- No mezclar cambios visuales con cambios backend o infra salvo tarea explicita.

## Verificacion minima

- Ejecutar checks de JS cuando aplique, por ejemplo `node --check app.js`.
- Abrir pagina afectada localmente o ambiente indicado.
- Probar desktop y mobile basico si toca UI.
- Revisar consola sin errores criticos.
- Confirmar que superficies no relacionadas siguen funcionando si fueron tocadas.

## Handoff

Indicar archivos cambiados, rutas revisadas, version/cache busting si aplica, pruebas ejecutadas y riesgos.
