## Motivo

Product/Architect decidio que esa direccion no es correcta:

- `admin.html` debe ser para revision interna.
- Agregar/editar servicios pertenece al panel empresa.

## Estado

Cancelada antes de implementacion.

Crear una nueva tarea para Web Dev:

```text
Panel empresa demo separado para crear/editar servicios.
```

El nuevo panel debe incluir:

- categorias como lista controlada,
- tipos de evento como opciones controladas,
- fotos del servicio con preview,
- persistencia demo local,
- y flujo de enviar a revision.
