# TASK-166: Web Dev - mejora UX/diseno enfocada

## Equipo asignado

Web Dev.

## Contexto

Prioridad P2. No iniciar antes de que login recurrente y cotizacion tengan contrato claro.

## Tarea

Pulir UX/diseno de forma enfocada sin redisenio completo.

## Alcance

- Claridad de CTAs principales.
- Estados de carga/exito/error.
- Legibilidad mobile.
- Consistencia visual en formularios de registro, panel y admin.
- Mantener la pagina publica actual como base.

## No tocar

- Reescritura de pagina publica.
- Backend/API.
- Cambios grandes de arquitectura.
- Ranking/pagos/CRM.

## Verificacion

- Desktop y mobile basico.
- No romper busqueda publica, registro, panel ni admin.
- Capturas o notas visuales antes/despues si aplica.

## Handoff esperado

Crear `tasks/TASK-166-HANDOFF.md` con:

- Cambios visuales puntuales.
- Archivos cambiados.
- Verificacion responsive.
- Riesgos.
- Recomendacion para QA.
