# Chat Start

Esta carpeta contiene los archivos de inicio para abrir chats especializados en Codex.

Uso recomendado:

1. Abrir un nuevo chat.
2. Pegar una instruccion como:

```text
Lee el archivo chat-start/WEB_DEV.md y sigue esas instrucciones.
```

3. El chat debe leer tambien los documentos base indicados en su archivo.
4. Cada chat debe trabajar una tarea pequena y concreta.

## Chats sugeridos

- `PRODUCT_ARCHITECT.md`: coordinacion central, decisiones, backlog.
- `WEB_DEV.md`: pagina publica, admin UI, frontend.
- `BACKEND_API.md`: Azure Functions, endpoints, validaciones.
- `INFRA_AZURE.md`: Azure, storage, CI/CD, seguridad.
- `QA.md`: pruebas, regresion, responsive, permisos.

## Regla principal

Los chats no deben inventar arquitectura nueva sin actualizar documentacion.

La fuente de verdad es:

- `AGENTS.md`
- `docs/`
- documentos del equipo correspondiente.
