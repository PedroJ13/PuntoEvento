# Incidentes Produccion

Este documento registra incidentes o reportes recibidos durante pruebas con usuarios reales, clientes amigos o primeras empresas.

No reemplaza `docs/MVP_RELEASE_STATUS.md`. Product / Architect / Release decide que incidentes se convierten en tareas.

## Formato

```text
ID:
Fecha:
Reportado por:
Ambiente/URL:
Superficie:
Resumen:
Pasos:
Resultado actual:
Resultado esperado:
Evidencia:
Severidad:
Tipo:
Estado:
Equipo sugerido:
Tarea relacionada:
Notas:
```

## Estados

- Nuevo.
- Necesita evidencia.
- En triage.
- Reproducido.
- No reproducible.
- Tarea creada.
- En correccion.
- Corregido pendiente QA.
- Cerrado.
- Aceptado como riesgo.
